CineVault

WDD 231 - Week 05

Site Name

Name: CineVault

Reason: I chose this name because it evokes the idea of a secure, organized "vault" where users can discover and safely store their favorite cinematic treasures.

Site Purpose

The purpose of CineVault is to provide a fast, modern interface for exploring the world of cinema. The site solves the common problem of "what should I watch tonight?" by allowing users to:

  • Browse the most popular and top-rated movies of the moment using the TMDB API.
  • Filter results by specific genres (Action, Comedy, Drama) to find exactly what fits their mood.
  • Save a personalized "Favorites" list directly in their browser (LocalStorage) so they never lose track of a movie they want to watch later.

Scenarios

Key questions the site will answer for the user:

  • Scenario 1: "What are the highest-rated Action movies released recently?" (This justifies the filtering and sorting functionality).
  • Scenario 2: "I found an interesting movie, but I don't have time to watch it right now. How can I save it to remember the title later?" (This justifies the LocalStorage functionality).

Color Schema

The site will use a "Dark Mode" aesthetic. This reduces eye strain and allows the colorful movie posters to stand out visually.

Color Usage:

  • Primary (#22254b): Main page background (Body).
  • Secondary (#373b69): Headers, movie cards, and footer background.
  • Accent (#ffa500): Call-to-action buttons, rating stars, and hover effects.
  • Text (#ffffff): All main text to ensure high contrast against the dark background.

Typography

Heading Font: 'Poppins', sans-serif

Used for all headings (h1-h6) and navigation links. It is a geometric, clean font that gives the site a modern app-like feel.

Body Font: 'Open Sans', sans-serif
